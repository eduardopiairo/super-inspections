# Inspections

An **Inspection** is a single occurrence of conducting a [Template](./templates.md) — someone
walking through the template's questions and recording answers.

## Fields

- `template_id` — required; which template this inspection is conducting
- `title` — e.g. "Kitchen Safety - Downtown Store"
- `status` — free-form string, defaults to `pending` (e.g. `pending`, `in_progress`, `completed`)
- `site_id` — optional; where the inspection is happening
- `assigned_user_id` — optional; who is conducting it
- `schedule_id` — set automatically when the inspection was generated by a [Schedule](./schedules.md);
  `null` for one-off, manually created inspections
- `created_at` / `completed_at` — timestamps; `completed_at` is set the first time `status`
  is patched to `completed`

## Answers

Each answer records a value for one of the template's questions:

- `question_id` — which question is being answered
- `value` — the response, shaped by the question's `response_type` (e.g. `true`/`false` for
  `yes_no`, a string for `text`/`date`, a chosen option for `multiple_choice`)

Answers are submitted via `PATCH`, keyed by `question_id` — patching the same question again
overwrites its previous answer rather than creating a duplicate.

## Actions

A failed or flagged answer commonly leads to an [Action](./actions.md) — Actions can reference a
specific `inspection_id` and `question_id` to record what needs fixing and why.

## API

| Method | Path                  | Description                                      |
|--------|-----------------------|---------------------------------------------------|
| GET    | `/inspections/`        | List inspections (summary, no answers)            |
| POST   | `/inspections/`        | Create an inspection against a template           |
| GET    | `/inspections/{id}`    | Get an inspection with its answers                |
| PATCH  | `/inspections/{id}`    | Submit/update answers and/or change status        |
| DELETE | `/inspections/{id}`    | Delete an inspection (cascades to answers/actions) |

See [backend/app/routers/inspections.py](../backend/app/routers/inspections.py).
